# Marketplace architecture

Investors browse `/marketplace`. Each card is an existing Pool. A pool contains facilities. Each facility is one approved fleet application. Investors subscribe to the pool. Capital is then split across facilities by priority.

Sensitive company files stay off the marketplace. Cards show counts, AssetFi risk, indicative lease yield, and remaining capacity.
